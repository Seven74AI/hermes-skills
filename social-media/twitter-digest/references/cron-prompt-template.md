# Cron Job Prompt Template — Twitter Digest

This template is used for cron jobs (frequency: daily at 7h). Copy and customize for each list.

## Dev/AI Digest

```yaml
job_id: <auto-generated>
name: "Twitter Digest — Dev/AI"
schedule: "0 7 * * *"
deliver: discord:<channel_id>
skills: [social-media/xurl]
enabled_toolsets: [terminal, web, file, skills]
```

### Prompt

```
Collect tweets from a Twitter list, tag them with 3 categorization dimensions, 
write to Notion + GitHub Pages, and send a clean digest to Discord. 
NO SUMMARIES — just the tweets themselves.

CRITICAL RULES:
1. REPLIES: If a tweet is a reply (starts with @username or conversation_id != id), 
   fetch the parent tweet via `xurl read TWEET_ID` and include both.
2. MEDIA: Extract all images, videos, and GIFs from tweet entities. For each tweet 
   with media, include the media URLs in the JSON.

CONTEXT:
- List ID: <LIST_ID>
- Notion DB: <DB_ID>
- GitHub Pages: https://<user>.github.io/twitter-digest/
- Discord: send_message target="discord:<channel_id>"
- Push script: /root/.hermes/scripts/push-digest.sh
- Source env: source ~/.hermes/.env (NOTION_API_KEY, GITHUB_TOKEN)
- Language: tweets in original, Discord labels in English

STEPS:
1. FETCH: xurl "/2/lists/<LIST_ID>/tweets?max_results=100&expansions=author_id,referenced_tweets.id&user.fields=username,name,profile_image_url&tweet.fields=public_metrics,created_at,entities,referenced_tweets,conversation_id,in_reply_to_user_id"
   Paginate 3-5 pages using next_token. Stop when ≥300 tweets or no next_token.
   Save each page: xurl "..." > /tmp/list-pageN.json
   Process with python3 /tmp/process.py (NOT python3 -c — Hermes blocks it)

2. FILTER: Remove RTs. Remove empty/link-only tweets with zero substance.
   Date filter: keep only yesterday + today tweets.

3. ENRICH REPLIES: For each reply, find parent in already-fetched data
   (use referenced_tweets[].id, NOT xurl read — costs extra credits).
   ~95% of parents are in the list data already.

4. TAG each tweet with 3 dimensions:
   - Themes (1-3): <domain-specific tags>
   - Signal (one): 🔴🟡🟢⚪
   - Source (one): Builder/Curator/Analyst/Community

5. BUILD JSON at /tmp/YYYY-MM-DD-<type>.json with date, list, tweets array.
   Include is_reply, parent, reply, media, themes, signal, source.

6. PUSH: source ~/.hermes/.env && bash /root/.hermes/scripts/push-digest.sh 
   /tmp/YYYY-MM-DD-<type>.json <type> YYYY-MM-DD

7. DISCORD: Build message grouped by Signal, respecting 2000-char limit.
   Read digest from /tmp/twitter-digest-data/data/YYYY-MM-DD-<type>.json
   (push-digest.sh deletes the original at /tmp/).

8. NOTION: Create page in DB <DB_ID> with all tweets as markdown.
   Fall back to curl if ntn api --json not available.

9. SEND to discord:<channel_id> with the formatted digest.
```
