# CI Debugging Reference

## When CI fails after dependency updates

### 1. Check which jobs failed
```bash
gh run view <RUN_ID> --repo owner/repo --json jobs --jq '.jobs[] | {name, conclusion}'
```

### 2. Get failed job logs
```bash
gh run view <RUN_ID> --repo owner/repo --log-failed
# or via API:
curl -sL -H "Authorization: Bearer $GITHUB_TOKEN" \
  "https://api.github.com/repos/owner/repo/actions/jobs/<JOB_ID>/logs" | grep "##[error]"
```

### 3. Reproduce locally (MANDATORY — do NOT fix blind)
```bash
# Always specify --repo on forks (gh defaults to upstream, not your fork)
gh run view <RUN_ID> --repo Owner/fork --log-failed

# TypeScript/ESLint/unit tests don't need a server:
npx tsc --noEmit
npm run lint
npx vitest run

# Playwright E2E with CI=true mimics GitHub Actions:
npm run build          # ⚠️ REQUIRED — server uses pre-built code from build/server/
CI=true npx playwright test tests/e2e/failing-test.test.ts --reporter=line
```
Without `npm run build` first, source changes to app code are NOT picked up — the `webServer` command (`start:mocks`) imports `build/server/index.js`. In CI, the build step runs before Playwright, so local runs must replicate that order.

### 4. Fix and validate locally before push

## Common CI failure patterns

### TypeScript: `Cannot find module './+types/*'`
Pre-existing, not from our changes. Generated by React Router typegen.

### TypeScript: `url` and `pattern` missing from loader/action args
React Router v7 changed types. Fix: add `url: new URL('http://localhost'), pattern: ''` to all `loader()`/`action()` calls in test files.

### ESLint: `Package subpath './eslint' is not defined`
@epic-web/config v3 removed the eslint export. Keep at v1 or migrate to oxlint.

### Playwright: `no such table: main.Currency`
DATABASE_URL mismatch between `.env.example` and actual DB path. Ensure `DATABASE_URL` matches `DATABASE_PATH`. Or `prisma migrate deploy` not running in CI step.

### Playwright: `Unique constraint failed on fields: (orderNumber)`
Parallel test workers (--workers=4) sharing one DB. Use `--workers=1`.

### Playwright: `ValidationError: Custom keyGenerator`
express-rate-limit v8 requires `ipKeyGenerator()` helper for IPv6.

### Playwright: `LibsqlError: URL_PARAM_NOT_SUPPORTED: connection_limit`
Prisma v7 libsql adapter doesn't support `?connection_limit=1`. Remove from DATABASE_URL.
